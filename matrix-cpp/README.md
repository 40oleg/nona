# Матричный калькулятор на C++

Порт `examples/compat/matrix-calculator.cjs`: те же операции, входные матрицы,
метод Гаусса — Жордана с выбором ведущей строки и относительный порог `1e-12`.
Измените A и B в `main()` и пересоберите. Ввода с клавиатуры нет.
Для плохо обусловленных матриц порог может отклонить математически обратимую
матрицу. Вычисления используют double; возможны округление и переполнение.
Числа печатаются через `%.17g`, поэтому дробные результаты могут выглядеть
иначе, чем кратчайшее десятичное представление JavaScript.

## Сборка из корня проекта в PowerShell

На этом компьютере установлен GCC 16.2.0 (MSYS2 UCRT64):

```powershell
cd C:\Users\helgus\projects\nona
$env:PATH = 'C:\msys64\ucrt64\bin;' + $env:PATH
g++.exe -std=c++17 -O2 -s -static -Wall -Wextra -Wpedantic -ffp-contract=off .\matrix-cpp\matrix-calculator.cpp -o .\matrix-cpp\matrix-calculator.exe
.\matrix-cpp\matrix-calculator.exe
(Get-Item .\matrix-cpp\matrix-calculator.exe).Length
```

`-O2` включает оптимизацию, `-s` удаляет таблицу символов, `-static` включает
библиотеки GCC/C++ в EXE. Остаются зависимости от системных DLL Windows
(KERNEL32 и UCRT), подтверждённые через `objdump -p`. DLL MinGW рядом не нужны.
`-ffp-contract=off` исключает объединение умножения и сложения в FMA.
