# GUI sample assets

`pixels.png` is Nona's small deterministic RGBA image fixture, created for
`tests/fixtures/gui/`. `Abel-Regular.ttf` is the pinned Abel font used by those
fixtures; its license is in `OFL.txt`. See the
[fixture provenance](../../../tests/fixtures/gui/README.md).

Distribute this directory beside the compiled ELF. Paths in the application
resolve relative to the executable, regardless of the current working directory.
