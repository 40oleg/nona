# Матричный калькулятор

[`examples/compat/matrix-calculator.cjs`](https://github.com/40oleg/nona/blob/main/examples/compat/matrix-calculator.cjs) складывает, вычитает и перемножает две матрицы, транспонирует A и вычисляет определитель и обратную матрицу для A. Он использует только язык и `console.log`, поэтому одна и та же программа работает и в Node.js, и как исполняемый файл Nona.

## Сборка и запуск

::: code-group

```sh [Windows]
node dist/cli.js build examples/compat/matrix-calculator.cjs -o build/matrix-calculator.exe
.\build\matrix-calculator.exe
```

```sh [Linux]
node dist/cli.js build examples/compat/matrix-calculator.cjs -o build/matrix-calculator --target linux-x64
./build/matrix-calculator
```

:::

```text
A:
2  1
1  1
B:
3  4
5  6
Transpose A:
2  1
1  1
A + B:
5  5
6  7
…
```

## Как изменить входные данные

Отредактируйте матрицы в конце исходника и соберите программу снова:

```js
const A = [[2, 1], [1, 1]];
const B = [[3, 4], [5, 6]];
```

Каждый вложенный массив — строка матрицы. Матрицы должны быть непустыми, прямоугольными и содержать конечные числа. Для сложения и вычитания нужны одинаковые размеры; для умножения число столбцов A должно совпадать с числом строк B; для определителя и обратной матрицы A должна быть квадратной. Ошибка в одной операции не останавливает остальные.

## Численные методы

Определитель и обратная матрица вычисляются методом Гаусса–Жордана с частичным выбором ведущего элемента в binary64. Если ведущий элемент не больше `1e-12`, умноженного на наибольшее абсолютное значение во входных данных, программа сообщает о нулевом определителе и отсутствии обратной матрицы. Это численный порог: он может отвергнуть плохо обусловленную матрицу, которая обратима в точной арифметике.

## Проверка

```sh
node scripts/check-matrix-calculator.mjs
```

Скрипт компилирует пример и его вариант с проверками, запускает оба исполняемых файла и сравнивает стандартный вывод, стандартный поток ошибок и коды выхода с Node.js: результаты операций, прямоугольные матрицы, перестановки строк, матрицы 1×1 и 3×3, вырожденные матрицы и восемь некорректных входов.
