# Поддержка языка

Nona реализует ECMA-262 11-го издания (ES2020) с документированными исключениями. На этой странице кратко описано, что поддерживается в **v0.8.0**; числа получены на закреплённой ревизии Test262, описанной на странице [Test262](/ru/reference/test262).

**Поддерживается** означает: реализовано и покрыто модульными тестами и Test262 в пределах, указанных в столбце «Примечания». Подробная матрица по возможностям с именами тестов — в [`docs/language-support.md`](https://github.com/40oleg/nona/blob/main/docs/language-support.md).

## Язык

| Область | Статус | Примечания |
| --- | --- | --- |
| Лексическая грамматика и литералы | Поддерживается | Десятичные, шестнадцатеричные, двоичные, восьмеричные и BigInt-литералы, Unicode-экранирование в идентификаторах и строках, шаблонные строки. Устаревшие восьмеричные литералы Annex B и HTML-подобные комментарии в нестрогих скриптах. Разделители в числах (ES2021) отклоняются. |
| `var`, `let`, `const`, TDZ | Поддерживается | Подъём (hoisting), блочная область видимости, привязки на каждую итерацию, конфликты объявлений как ранние ошибки. |
| Функции | Поддерживается | Объявления и выражения, замыкания, `arguments` (связанный и несвязанный), параметры по умолчанию и rest-параметры, деструктуризация параметров, `this`, `new.target`, `Function.prototype.toString` с точным исходным текстом. |
| Стрелочные функции | Поддерживается | Лексические `this`, `arguments`, `new.target` и `super`; `async`-стрелки. |
| Классы | Поддерживается | Объявления и выражения, конструкторы, методы и аксессоры экземпляра и статические, вычисляемые имена, наследование, включая встроенные классы и `extends null`, `super()` и `super.x`. Поля классов и приватные имена (ES2022) не поддерживаются. |
| Деструктуризация, spread | Поддерживается | Объявления, присваивания, параметры, цели `for-in`/`for-of`; spread в массивах, объектах, вызовах и `new`. |
| Итераторы и генераторы | Поддерживается | Протокол итераторов, `for-of`, функции и методы-генераторы, `yield*`, `return`/`throw`. |
| Async-функции | Поддерживается | Async-функции, стрелки и методы, `await`, async-генераторы и `for await`, с порядком заданий ES2020. |
| Операторы | Поддерживается | Включая `**`, optional chaining, `??`, `delete`, `in`, `instanceof` с `Symbol.hasInstance`, арифметику и сравнения BigInt. |
| Управление потоком | Поддерживается | Все инструкции, метки, `try`/`catch`/`finally` со значениями завершения, `switch`, `debugger` (ничего не делает). |
| Строгий режим | Поддерживается | Директивы в прологе, строгий `this`, ранние ошибки и ограничения во время исполнения. |
| `with` | Поддерживается | Только в нестрогих скриптах, с `Symbol.unscopables`. |
| Proper tail calls | Поддерживается | В строгом коде. |
| Модули | Поддерживается | `import`/`export` во всех формах, циклы, live bindings, объекты пространств имён, `import.meta`, `import()` модулей, известных при компиляции. `await` верхнего уровня (ES2022) не поддерживается. |
| `eval`, `Function` | Частично | Исходник, известный при компиляции, компилируется заранее с полной семантикой прямого и косвенного `eval`; исходник, вычисленный во время исполнения, бросает `EvalError`. См. [Совместимость](/ru/guide/compatibility#eval-and-function). |
| Annex B | Поддерживается | Семантика веб-совместимости для функций в блоках, `__proto__`, устаревший синтаксис RegExp, `escape`/`unescape`, HTML-методы String и другое. |

## Встроенные объекты

| Область | Статус | Примечания |
| --- | --- | --- |
| Object, Function, Boolean, Symbol, Error | Поддерживается | Включая дескрипторы свойств, операции целостности, глобальные и well-known символы. |
| Number, Math, функции URI | Поддерживается | Кратчайшее форматирование чисел с точным обратным разбором, `toFixed`/`toExponential`/`toPrecision`, все функции `Math` из ES2020. |
| String | Поддерживается | Методы ES2020, нормализация Unicode, `localeCompare` без локальных данных ECMA-402. |
| RegExp | Поддерживается | Именованные группы, lookbehind, флаги `s`, `u`, `y` и `g`, Unicode property escapes, `matchAll`. Движок — VM с возвратами, написанная как прелюдия; он медленнее, чем в V8. |
| Array | Поддерживается | Все методы ES2020, species, дыры и очень большие длины. |
| Date, JSON | Поддерживается | Разбор и форматирование дат в UTC и местном времени, `JSON.parse` с reviver, `JSON.stringify` с replacer и отступами. |
| Map, Set, WeakMap, WeakSet | Поддерживается | Семантика эфемеронов для слабых коллекций. |
| ArrayBuffer, DataView, typed arrays | Поддерживается | Все 11 типов typed arrays, включая BigInt-массивы, отсоединение буферов, species. |
| SharedArrayBuffer, Atomics | Поддерживается | Включая `Atomics.wait`/`notify` с агентами-потоками (используются в Test262). |
| Proxy, Reflect | Поддерживается | Все ловушки и инварианты. |
| Promise | Поддерживается | `all`, `allSettled`, `race`, `finally`, thenable-объекты и сообщения о необработанных отказах. |
| `globalThis`, `console.log` | Поддерживается | `console.log` пишет UTF-8 в стандартный вывод. |

## После ES2020

Возможности более поздних изданий не поддерживаются: поля классов и приватные имена, статические блоки, `Promise.any`, `WeakRef` и `FinalizationRegistry`, логические операторы присваивания, разделители в числах, флаг RegExp `v`, `await` верхнего уровня и `Array.prototype.at`. Некоторые более поздние дополнения библиотеки, например `String.prototype.replaceAll`, доступны. Там, где закреплённая ревизия Test262 уже проверяет более новую семантику возможностей ES2020, Nona следует Test262; эти случаи перечислены на странице [Test262](/ru/reference/test262#semantics-newer-than-es2020-in-the-pinned-test262).

API хоста, не входящие в ECMAScript, — таймеры, `process`, `node:fs`, `TextEncoder`/`TextDecoder` и FFI — описаны в [Справочнике](/ru/reference/modules).

## Результаты Test262

Полный прогон закреплённого Test262 на Windows x64 (возможности ES2020 и более ранние):

| Каталог | Пройдено / применимо | Оставшиеся отказы |
| --- | --- | --- |
| `language/` | 22436 / 22492 | 44 `eval`, 1 более новая семантика, 11 прочих |
| `built-ins/` | 15868 / 15933 | 16 `eval`, 12 более новая семантика, 37 прочих |
| `built-ins/Atomics` (агенты) | 268 / 268 | — |
| `annexB/` | 996 / 1016 | 20 `eval` |

Отказы «`eval`» используют исходный текст, вычисленный во время исполнения, `$262.evalScript` или другие realms; тесты «более новой семантики» проверяют поведение из поздних изданий под старым или отсутствующим тегом возможности. Оставшиеся отказы перечислены на [странице статуса](/ru/guide/status).
