# ম্যাট্রিক্স ক্যালকুলেটর

[`examples/compat/matrix-calculator.cjs`](https://github.com/40oleg/nona/blob/main/examples/compat/matrix-calculator.cjs) দুটি ম্যাট্রিক্স যোগ, বিয়োগ ও গুণ করে, A-এর ট্রান্সপোজ বের করে এবং A-এর ডিটারমিন্যান্ট ও ইনভার্স গণনা করে। এটি কেবল ভাষা ও `console.log` ব্যবহার করে, তাই একই প্রোগ্রাম Node.js-এও চলে এবং Nona এক্সিকিউটেবল হিসেবেও।

## বিল্ড ও চালানো

::: code-group

```sh [Windows]
node dist/cli.js build examples/compat/matrix-calculator.cjs -o build/matrix-calculator.exe
.\build\matrix-calculator.exe
```

```sh [Linux]
node dist/cli.js build examples/compat/matrix-calculator.cjs -o build/matrix-calculator --target linux-x64
./build/matrix-calculator
```

:::

```text
A:
2  1
1  1
B:
3  4
5  6
Transpose A:
2  1
1  1
A + B:
5  5
6  7
…
```

## ইনপুট পরিবর্তন

সোর্সের শেষে ম্যাট্রিক্সগুলো সম্পাদনা করুন এবং আবার বিল্ড করুন:

```js
const A = [[2, 1], [1, 1]];
const B = [[3, 4], [5, 6]];
```

প্রতিটি ভেতরের অ্যারে একটি সারি। ম্যাট্রিক্সগুলো খালি হতে পারবে না, আয়তাকার হতে হবে এবং সসীম (finite) সংখ্যা থাকতে হবে। যোগ ও বিয়োগের জন্য সমান আকার দরকার; গুণের জন্য A-তে ততগুলো কলাম দরকার যতগুলো সারি B-তে আছে; ডিটারমিন্যান্ট ও ইনভার্সের জন্য A বর্গাকার হতে হবে। একটি অপারেশনের ত্রুটি অন্যগুলোকে থামায় না।

## সংখ্যাগত গণনা

ডিটারমিন্যান্ট ও ইনভার্স binary64-এ আংশিক পিভটিং (partial pivoting)-সহ Gauss–Jordan এলিমিনেশন ব্যবহার করে। যদি কোনো পিভট সবচেয়ে বড় পরম ইনপুট মানের `1e-12` গুণের চেয়ে বড় না হয়, তাহলে প্রোগ্রাম শূন্য ডিটারমিন্যান্ট জানায় এবং কোনো ইনভার্স দেয় না। এটি একটি সংখ্যাগত সীমা: এটি এমন একটি ill-conditioned ম্যাট্রিক্সও প্রত্যাখ্যান করতে পারে, যা নির্ভুল পাটিগণিতে ইনভার্টিবল।

## যাচাই

```sh
node scripts/check-matrix-calculator.mjs
```

স্ক্রিপ্টটি উদাহরণটি এবং assertion-সহ একটি সংস্করণ কম্পাইল করে, দুটি এক্সিকিউটেবলই চালায় এবং স্ট্যান্ডার্ড আউটপুট, স্ট্যান্ডার্ড এরর ও এক্সিট কোড Node.js-এর সঙ্গে তুলনা করে: অপারেশনের ফলাফল, আয়তাকার ম্যাট্রিক্স, সারি অদলবদল, 1×1 ও 3×3 ম্যাট্রিক্স, সিঙ্গুলার ম্যাট্রিক্স এবং আটটি অবৈধ ইনপুট।
