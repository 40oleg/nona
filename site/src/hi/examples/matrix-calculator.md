# मैट्रिक्स कैलकुलेटर

[`examples/compat/matrix-calculator.cjs`](https://github.com/40oleg/nona/blob/main/examples/compat/matrix-calculator.cjs) दो मैट्रिक्स को जोड़ता, घटाता और गुणा करता है, A का ट्रांसपोज़ बनाता है और A का डिटर्मिनेंट और इनवर्स निकालता है। यह केवल भाषा और `console.log` का उपयोग करता है, इसलिए वही प्रोग्राम Node.js में भी चलता है और Nona एक्ज़ीक्यूटेबल के रूप में भी।

## बनाएँ और चलाएँ

::: code-group

```sh [Windows]
node dist/cli.js build examples/compat/matrix-calculator.cjs -o build/matrix-calculator.exe
.\build\matrix-calculator.exe
```

```sh [Linux]
node dist/cli.js build examples/compat/matrix-calculator.cjs -o build/matrix-calculator --target linux-x64
./build/matrix-calculator
```

:::

```text
A:
2  1
1  1
B:
3  4
5  6
Transpose A:
2  1
1  1
A + B:
5  5
6  7
…
```

## इनपुट बदलना

सोर्स के अंत में मैट्रिक्स बदलें और फिर से बिल्ड करें:

```js
const A = [[2, 1], [1, 1]];
const B = [[3, 4], [5, 6]];
```

हर भीतरी ऐरे एक पंक्ति है। मैट्रिक्स ख़ाली नहीं होने चाहिए, आयताकार होने चाहिए और उनमें सीमित (finite) संख्याएँ होनी चाहिए। जोड़ और घटाव के लिए समान आकार चाहिए; गुणा के लिए A में उतने कॉलम चाहिए जितनी B में पंक्तियाँ हैं; डिटर्मिनेंट और इनवर्स के लिए A वर्ग मैट्रिक्स होना चाहिए। एक ऑपरेशन में त्रुटि बाकी ऑपरेशनों को नहीं रोकती।

## संख्यात्मक गणना

डिटर्मिनेंट और इनवर्स binary64 में आंशिक पिवटिंग (partial pivoting) के साथ Gauss–Jordan एलिमिनेशन का उपयोग करते हैं। अगर कोई पिवट सबसे बड़े निरपेक्ष इनपुट मान के `1e-12` गुना से बड़ा नहीं है, तो प्रोग्राम डिटर्मिनेंट को शून्य बताता है और इनवर्स नहीं देता। यह एक संख्यात्मक सीमा है: यह ऐसे ill-conditioned मैट्रिक्स को भी अस्वीकार कर सकती है जो सटीक अंकगणित में इनवर्टिबल है।

## सत्यापन

```sh
node scripts/check-matrix-calculator.mjs
```

स्क्रिप्ट उदाहरण और assertions वाला एक संस्करण कंपाइल करती है, दोनों एक्ज़ीक्यूटेबल चलाती है और स्टैंडर्ड आउटपुट, स्टैंडर्ड एरर और exit कोड की तुलना Node.js से करती है: ऑपरेशनों के परिणाम, आयताकार मैट्रिक्स, पंक्तियों की अदला-बदली, 1×1 और 3×3 मैट्रिक्स, सिंगुलर मैट्रिक्स और आठ अमान्य इनपुट।
