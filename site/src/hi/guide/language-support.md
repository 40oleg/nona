# भाषा समर्थन

Nona दस्तावेज़ित अपवादों के साथ ECMA-262 के 11वें संस्करण (ES2020) को लक्ष्य करता है। यह पेज बताता है कि **v0.8.0** में क्या समर्थित है; आँकड़े [Test262](/hi/reference/test262) पेज पर बताए गए पिन किए गए Test262 रिविज़न से आते हैं।

**समर्थित** का अर्थ है: लागू है और "टिप्पणियाँ" कॉलम में बताई गई सीमाओं के भीतर यूनिट टेस्ट और Test262 से कवर है। टेस्ट के नामों के साथ हर फ़ीचर की विस्तृत तालिका [`docs/language-support.md`](https://github.com/40oleg/nona/blob/main/docs/language-support.md) (रूसी में) में रखी गई है।

## भाषा

| क्षेत्र | स्थिति | टिप्पणियाँ |
| --- | --- | --- |
| लेक्सिकल ग्रामर और लिटरल | समर्थित | दशमलव, हेक्स, बाइनरी, ऑक्टल और BigInt लिटरल, आइडेंटिफ़ायर और स्ट्रिंग में Unicode एस्केप, टेम्पलेट लिटरल। नॉन-स्ट्रिक्ट स्क्रिप्ट में Annex B के पुराने ऑक्टल और HTML-जैसे कमेंट। न्यूमेरिक सेपरेटर (ES2021) अस्वीकार किए जाते हैं। |
| `var`, `let`, `const`, TDZ | समर्थित | होइस्टिंग, ब्लॉक स्कोप, हर इटरेशन की अलग बाइंडिंग, डिक्लेरेशन टकराव अर्ली एरर के रूप में। |
| फ़ंक्शन | समर्थित | डिक्लेरेशन और एक्सप्रेशन, क्लोज़र, `arguments` (मैप्ड और अनमैप्ड), डिफ़ॉल्ट और rest पैरामीटर, डीस्ट्रक्चरिंग पैरामीटर, `this`, `new.target`, सटीक सोर्स टेक्स्ट के साथ `Function.prototype.toString`। |
| ऐरो फ़ंक्शन | समर्थित | लेक्सिकल `this`, `arguments`, `new.target` और `super`; `async` ऐरो। |
| क्लास | समर्थित | डिक्लेरेशन और एक्सप्रेशन, कंस्ट्रक्टर, इंस्टेंस और स्टैटिक मेथड व एक्सेसर, कंप्यूटेड नाम, इनहेरिटेंस (बिल्ट-इन और `extends null` सहित), `super()` और `super.x`। क्लास फ़ील्ड और प्राइवेट नाम (ES2022) समर्थित नहीं हैं। |
| डीस्ट्रक्चरिंग, spread | समर्थित | डिक्लेरेशन, असाइनमेंट, पैरामीटर, `for-in`/`for-of` टार्गेट; ऐरे, ऑब्जेक्ट, कॉल और `new` में spread। |
| इटरेटर और जनरेटर | समर्थित | इटरेटर प्रोटोकॉल, `for-of`, जनरेटर फ़ंक्शन और मेथड, `yield*`, `return`/`throw`। |
| async फ़ंक्शन | समर्थित | async फ़ंक्शन, ऐरो और मेथड, `await`, async जनरेटर और `for await`, ES2020 के जॉब क्रम के साथ। |
| ऑपरेटर | समर्थित | `**`, ऑप्शनल चेनिंग, `??`, `delete`, `in`, `Symbol.hasInstance` के साथ `instanceof`, BigInt अंकगणित और तुलना सहित। |
| कंट्रोल फ़्लो | समर्थित | सभी स्टेटमेंट, लेबल, कम्प्लीशन वैल्यू के साथ `try`/`catch`/`finally`, `switch`, `debugger` (कुछ नहीं करता)। |
| स्ट्रिक्ट मोड | समर्थित | डायरेक्टिव प्रोलॉग, स्ट्रिक्ट `this`, अर्ली एरर और रनटाइम प्रतिबंध। |
| `with` | समर्थित | केवल नॉन-स्ट्रिक्ट स्क्रिप्ट में, `Symbol.unscopables` के साथ। |
| प्रॉपर टेल कॉल | समर्थित | स्ट्रिक्ट कोड में। |
| मॉड्यूल | समर्थित | सभी रूपों में `import`/`export`, साइकिल, लाइव बाइंडिंग, नेमस्पेस ऑब्जेक्ट, `import.meta`, कंपाइल के समय ज्ञात मॉड्यूल का `import()`। टॉप-लेवल `await` (ES2022) समर्थित नहीं है। |
| `eval`, `Function` | आंशिक | कंपाइल के समय ज्ञात सोर्स पहले से कंपाइल होता है, डायरेक्ट और इनडायरेक्ट `eval` की पूरी सिमैंटिक्स के साथ; रनटाइम पर बना सोर्स `EvalError` फेंकता है। देखें [संगतता](/hi/guide/compatibility#eval-and-function)। |
| Annex B | समर्थित | ब्लॉक के अंदर फ़ंक्शन, `__proto__`, पुराना RegExp सिंटैक्स, `escape`/`unescape`, String के HTML मेथड आदि के लिए वेब-कम्पैटिबिलिटी सिमैंटिक्स। |

## बिल्ट-इन

| क्षेत्र | स्थिति | टिप्पणियाँ |
| --- | --- | --- |
| Object, Function, Boolean, Symbol, Error | समर्थित | प्रॉपर्टी डिस्क्रिप्टर, इंटीग्रिटी ऑपरेशन और ग्लोबल व well-known सिंबल सहित। |
| Number, Math, URI फ़ंक्शन | समर्थित | सबसे छोटा राउंड-ट्रिप नंबर फ़ॉर्मैटिंग, `toFixed`/`toExponential`/`toPrecision`, ES2020 के सभी `Math` फ़ंक्शन। |
| String | समर्थित | ES2020 मेथड, Unicode नॉर्मलाइज़ेशन, ECMA-402 लोकेल डेटा के बिना `localeCompare`। |
| RegExp | समर्थित | नामित ग्रुप, lookbehind, `s`, `u`, `y` और `g` फ़्लैग, Unicode property escapes, `matchAll`। इंजन प्रील्यूड के रूप में लिखी गई बैकट्रैकिंग VM है; यह V8 से धीमा है। |
| Array | समर्थित | ES2020 के सभी मेथड, species, होल और बहुत बड़ी लंबाई। |
| Date, JSON | समर्थित | UTC और लोकल समय में तारीख़ पार्स और फ़ॉर्मैट करना, reviver के साथ `JSON.parse`, replacer और इंडेंटेशन के साथ `JSON.stringify`। |
| Map, Set, WeakMap, WeakSet | समर्थित | वीक कलेक्शन के लिए ephemeron सिमैंटिक्स। |
| ArrayBuffer, DataView, टाइप्ड ऐरे | समर्थित | BigInt ऐरे सहित सभी 11 तरह के टाइप्ड ऐरे, डिटैचमेंट, species। |
| SharedArrayBuffer, Atomics | समर्थित | वर्कर एजेंट के साथ `Atomics.wait`/`notify` सहित (Test262 इनका उपयोग करता है)। |
| Proxy, Reflect | समर्थित | सभी ट्रैप और इनवेरिएंट। |
| Promise | समर्थित | `all`, `allSettled`, `race`, `finally`, thenable और अनहैंडल्ड रिजेक्शन की रिपोर्टिंग। |
| `globalThis`, `console.log` | समर्थित | `console.log` स्टैंडर्ड आउटपुट पर UTF-8 लिखता है। |

## ES2020 के बाद

बाद के संस्करणों के फ़ीचर समर्थित नहीं हैं: क्लास फ़ील्ड और प्राइवेट नाम, स्टैटिक ब्लॉक, `Promise.any`, `WeakRef` और `FinalizationRegistry`, लॉजिकल असाइनमेंट ऑपरेटर, न्यूमेरिक सेपरेटर, RegExp का `v` फ़्लैग, टॉप-लेवल `await` और `Array.prototype.at`। लाइब्रेरी में बाद में जोड़ी गई कुछ चीज़ें, जैसे `String.prototype.replaceAll`, उपलब्ध हैं। जहाँ पिन किया गया Test262 रिविज़न ES2020 फ़ीचर के लिए पहले से नई सिमैंटिक्स जाँचता है, वहाँ Nona Test262 का पालन करता है; [Test262](/hi/reference/test262#semantics-newer-than-es2020-in-the-pinned-test262) पेज पर ये मामले सूचीबद्ध हैं।

ECMAScript का हिस्सा न होने वाले होस्ट API — टाइमर, `process`, `node:fs`, `TextEncoder`/`TextDecoder` और FFI — [संदर्भ](/hi/reference/modules) में वर्णित हैं।

## Test262 परिणाम

Windows x64 पर पिन किए गए Test262 का पूरा रन (ES2020 और उससे पहले के फ़ीचर):

| डायरेक्टरी | पास / लागू | बचे फ़ेल्योर |
| --- | --- | --- |
| `language/` | 22436 / 22492 | 44 `eval`, 1 नई सिमैंटिक्स, 11 अन्य |
| `built-ins/` | 15868 / 15933 | 16 `eval`, 12 नई सिमैंटिक्स, 37 अन्य |
| `built-ins/Atomics` (एजेंट) | 268 / 268 | — |
| `annexB/` | 996 / 1016 | 20 `eval` |

"`eval`" फ़ेल्योर रनटाइम पर बना सोर्स टेक्स्ट, `$262.evalScript` या दूसरे realm इस्तेमाल करते हैं; "नई सिमैंटिक्स" वाले टेस्ट पुराने या ग़ायब फ़ीचर टैग के तहत बाद के संस्करणों का व्यवहार जाँचते हैं। [स्थिति पेज](/hi/guide/status) पर बचे फ़ेल्योर की सूची है।

Script functions can shadow built-in and host global names such as `escape`, `unescape`, `process`, timers and `TextEncoder`/`TextDecoder`. Runtime initialization completes first; declarations install writable, enumerable, nonconfigurable global properties.
