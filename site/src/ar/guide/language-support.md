# دعم اللغة

يستهدف Nona الإصدار الحادي عشر من ECMA-262 ‏(ES2020) مع استثناءات موثّقة. تلخّص هذه الصفحة ما هو مدعوم في **v0.8.0**؛ والأرقام مأخوذة من مراجعة Test262 المثبَّتة الموصوفة في صفحة [Test262](/ar/reference/test262).

**مدعوم** يعني أن الميزة منفَّذة ومغطّاة باختبارات الوحدة وبـ Test262 ضمن الحدود المذكورة في عمود الملاحظات. أما المصفوفة التفصيلية لكل ميزة مع أسماء الاختبارات فموجودة في [`docs/language-support.md`](https://github.com/40oleg/nona/blob/main/docs/language-support.md) (بالروسية).

## اللغة

| المجال | الحالة | ملاحظات |
| --- | --- | --- |
| القواعد المعجمية والقيم الحرفية | مدعوم | القيم الحرفية العشرية والست عشرية والثنائية والثمانية وBigInt، وتهريب Unicode في المعرّفات والسلاسل، والقوالب الحرفية. الأعداد الثمانية القديمة والتعليقات الشبيهة بـ HTML من Annex B في السكربتات غير الصارمة. تُرفض فواصل الأعداد (ES2021). |
| `var` و`let` و`const` وTDZ | مدعوم | الرفع (hoisting)، ونطاق الكتلة، والارتباطات لكل تكرار، وتعارض التصريحات كأخطاء مبكرة. |
| الدوال | مدعوم | التصريحات والتعابير، والإغلاقات، و`arguments` (المعيَّن وغير المعيَّن)، والمعاملات الافتراضية وrest، والمعاملات المفكَّكة، و`this`، و`new.target`، و`Function.prototype.toString` بالنص المصدري الدقيق. |
| الدوال السهمية | مدعوم | `this` و`arguments` و`new.target` و`super` معجمية؛ ودوال سهمية `async`. |
| الأصناف | مدعوم | التصريحات والتعابير، والمُنشئات، وتوابع ومُوصِّلات النسخ والتوابع الساكنة، والأسماء المحسوبة، والوراثة بما فيها وراثة الكائنات المدمجة و`extends null`، و`super()` و`super.x`. حقول الأصناف والأسماء الخاصة (ES2022) غير مدعومة. |
| التفكيك وspread | مدعوم | التصريحات والإسنادات والمعاملات وأهداف `for-in`/`for-of`؛ وspread في المصفوفات والكائنات والاستدعاءات و`new`. |
| المكرِّرات والمولّدات | مدعوم | بروتوكول التكرار، و`for-of`، ودوال وتوابع المولّدات، و`yield*`، و`return`/`throw`. |
| الدوال غير المتزامنة | مدعوم | الدوال والدوال السهمية والتوابع غير المتزامنة، و`await`، والمولّدات غير المتزامنة و`for await`، بترتيب المهام في ES2020. |
| العوامل | مدعوم | بما فيها `**` والتسلسل الاختياري و`??` و`delete` و`in` و`instanceof` مع `Symbol.hasInstance`، وحساب BigInt ومقارناته. |
| التحكم في التدفق | مدعوم | جميع العبارات، والتسميات، و`try`/`catch`/`finally` مع قيم الإكمال، و`switch`، و`debugger` (بلا أثر). |
| الوضع الصارم | مدعوم | مقدّمات التوجيهات، و`this` الصارم، والأخطاء المبكرة، والقيود وقت التشغيل. |
| `with` | مدعوم | في السكربتات غير الصارمة فقط، مع `Symbol.unscopables`. |
| استدعاءات الذيل الصحيحة | مدعوم | في الشيفرة الصارمة. |
| الوحدات | مدعوم | `import`/`export` بجميع أشكالهما، والدورات، والارتباطات الحية، وكائنات فضاءات الأسماء، و`import.meta`، و`import()` للوحدات المعروفة وقت الترجمة. `await` في المستوى الأعلى (ES2022) غير مدعوم. |
| `eval` و`Function` | جزئي | الشيفرة المعروفة وقت الترجمة تُترجَم مسبقًا مع الدلالات الكاملة لـ `eval` المباشر وغير المباشر؛ والشيفرة المحسوبة وقت التشغيل ترمي `EvalError`. راجع [التوافق](/ar/guide/compatibility#eval-and-function). |
| Annex B | مدعوم | دلالات التوافق مع الويب للدوال داخل الكتل، و`__proto__`، وصيغة RegExp القديمة، و`escape`/`unescape`، وتوابع HTML في String، وغيرها. |

## الكائنات المدمجة

| المجال | الحالة | ملاحظات |
| --- | --- | --- |
| Object وFunction وBoolean وSymbol وError | مدعوم | بما فيها واصفات الخصائص وعمليات السلامة والرموز العامة والمعروفة (well-known). |
| Number وMath ودوال URI | مدعوم | أقصر تنسيق للأعداد قابل للاسترجاع، و`toFixed`/`toExponential`/`toPrecision`، وجميع دوال `Math` في ES2020. |
| String | مدعوم | توابع ES2020، وتطبيع Unicode، و`localeCompare` دون بيانات المحلية من ECMA-402. |
| RegExp | مدعوم | المجموعات المسمّاة، وlookbehind، والأعلام `s` و`u` و`y` و`g`، وUnicode property escapes، و`matchAll`. المحرك آلة افتراضية بالتراجع (backtracking) مكتوبة كمقدّمة، وهو أبطأ من محرك V8. |
| Array | مدعوم | جميع توابع ES2020، وspecies، والثغرات، والأطوال الكبيرة جدًا. |
| Date وJSON | مدعوم | تحليل التواريخ وتنسيقها بتوقيت UTC والتوقيت المحلي، و`JSON.parse` مع reviver، و`JSON.stringify` مع replacer والإزاحة. |
| Map وSet وWeakMap وWeakSet | مدعوم | دلالات ephemeron للمجموعات الضعيفة. |
| ArrayBuffer وDataView والمصفوفات المنمَّطة | مدعوم | جميع أنواع المصفوفات المنمَّطة الأحد عشر، بما فيها مصفوفات BigInt، والفصل (detach)، وspecies. |
| SharedArrayBuffer وAtomics | مدعوم | بما فيها `Atomics.wait`/`notify` مع وكلاء عاملين (يستخدمها Test262). |
| Proxy وReflect | مدعوم | جميع المصائد والثوابت. |
| Promise | مدعوم | `all` و`allSettled` و`race` و`finally` والكائنات القابلة للانتظار (thenables) والإبلاغ عن حالات الرفض غير المعالَجة. |
| `globalThis` و`console.log` | مدعوم | يكتب `console.log` بترميز UTF-8 إلى المخرج القياسي. |

## ما بعد ES2020

ميزات الإصدارات اللاحقة غير مدعومة: حقول الأصناف والأسماء الخاصة، والكتل الساكنة، و`Promise.any`، و`WeakRef` و`FinalizationRegistry`، وعوامل الإسناد المنطقي، وفواصل الأعداد، والعلَم `v` في RegExp، و`await` في المستوى الأعلى، و`Array.prototype.at`. وبعض الإضافات اللاحقة إلى المكتبة متاحة، مثل `String.prototype.replaceAll`. وحين تتحقق مراجعة Test262 المثبَّتة بالفعل من دلالات أحدث لميزات ES2020، يتبع Nona معيار Test262؛ وتسرد صفحة [Test262](/ar/reference/test262#semantics-newer-than-es2020-in-the-pinned-test262) هذه الحالات.

واجهات المضيف التي ليست جزءًا من ECMAScript، أي المؤقتات و`process` و`node:fs` و`TextEncoder`/`TextDecoder` وFFI، موصوفة في [المرجع](/ar/reference/modules).

## نتائج Test262

تشغيل كامل لـ Test262 المثبَّت على Windows x64 (ميزات ES2020 وما قبله):

| المجلد | الناجحة / القابلة للتطبيق | الإخفاقات المتبقية |
| --- | --- | --- |
| `language/` | 22436 / 22492 | 44 `eval`، و1 دلالات أحدث، و11 أخرى |
| `built-ins/` | 15868 / 15933 | 16 `eval`، و12 دلالات أحدث، و37 أخرى |
| `built-ins/Atomics` (الوكلاء) | 268 / 268 | — |
| `annexB/` | 996 / 1016 | 20 `eval` |

إخفاقات «`eval`» تستخدم نصًا مصدريًا محسوبًا وقت التشغيل أو `$262.evalScript` أو عوالم (realms) أخرى؛ أما اختبارات «الدلالات الأحدث» فتتحقق من سلوك من إصدارات لاحقة تحت وسم ميزة قديم أو مفقود. وتسرد [صفحة الحالة](/ar/guide/status) الإخفاقات المتبقية.

Script functions can shadow built-in and host global names such as `escape`, `unescape`, `process`, timers and `TextEncoder`/`TextDecoder`. Runtime initialization completes first; declarations install writable, enumerable, nonconfigurable global properties.
