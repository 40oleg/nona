# سطر الأوامر

## الصيغة العامة

```text
Nona 0.24.0 — JavaScript subset to native executables
Usage: nona build <input.js|package directory> -o <output> [--target win32-x64|linux-x64|linux-arm64|win32-arm64|darwin-x64|darwin-arm64|freebsd-x64|openbsd-x64] [--module]
       [--conditions name]... [--full-runtime] [--link part,...] [--print-link]
       [--call-stats] [--coverage dir] [--print-asm]
       [--subsystem console|windows] [--icon app.ico] [--manifest app.manifest]
       [--version-info version.json]
       (.mjs inputs are compiled as modules)
       nona --help | --version
```

يقبل الملف التنفيذي المنشور `nona` هذه الوسائط. ومن نسخة مستنسخة من المستودع شغّل `node dist/cli.js …`؛ وبعد `npm link` يصبح الأمر نفسه متاحًا باسم `nona`.

## الخيارات

| الخيار               | القيمة                                          | الوصف                                                                                                                                                                                                                                |
| -------------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `-o`                 | مسار                                            | ملف الناتج. إلزامي. تُنشأ المجلدات الناقصة.                                                                                                                                                                                          |
| `--target`           | [Native platforms](/reference/native-platforms) | PE32+, ELF64 or Mach-O64; default: host OS and CPU.                                                                                                                                                                                  |
| `--module`           | —                                               | ترجمة المدخل كوحدة ES. المدخلات المنتهية بـ `.mjs` وحدات تلقائيًا.                                                                                                                                                                   |
| `--conditions`, `-C` | اسم                                             | إضافة شرط `exports`/`imports` من package.json يُجرَّب قبل شروط Nona نفسها (`nona` و`node` و`import` أو `require` و`default`)؛ وتعمل الصيغة `--conditions=name` أيضًا. يمكن تكراره. راجع [حزم npm](/reference/npm#resolution).        |
| `--print-asm`        | —                                               | طباعة شيفرة التجميع x86-64 المولَّدة لدوال البرنامج نفسه (دون بيئة التشغيل ومقدماتها) على stdout: وسم كل دالة، ثم سطر لكل تعليمة يضم إزاحتها وبايتاتها المرمَّزة ونصها بصياغة Intel. مع هذا الخيار يمكن حذف `-o`. لأهداف x86-64 فقط. |
| `--link`             | أجزاء مفصولة بفواصل                             | اربط أيضًا هذه الأجزاء الاختيارية (مثل `--link proxy,regexp`) لبرنامج لا يصل إليها إلا عبر أسماء تُبنى وقت التشغيل. أرخص من `--full-runtime`؛ يعرض `--print-link` أسماء الأجزاء.                                                     |
| `--print-link`       | —                                               | اطبع أجزاء بيئة التشغيل الاختيارية المربوطة وسبب ربط كل منها: الاسم في الشيفرة المصدرية الذي اختاره، أو `--link`، أو الجزء الذي يحتاجه. يمكن عندها حذف `-o`.                                                                         |
| `--subsystem`        | `console` (الافتراضي)، `windows`                | برنامج Windows رسومي بلا نافذة طرفية. للمنصة `win32-x64` فقط. البرنامج الرسومي بلا `--manifest` يحصل على بيان افتراضي.                                                                                                               |
| `--icon`             | ملف `.ico`                                      | تضمين كل صور ملف الأيقونة. للمنصة `win32-x64` فقط.                                                                                                                                                                                   |
| `--manifest`         | ملف XML                                         | تضمين بيان تطبيق. يجب أن يكون صالحًا: يرفض Windows تشغيل برنامج ببيان تالف. للمنصة `win32-x64` فقط.                                                                                                                                  |
| `--version-info`     | ملف JSON                                        | تضمين معلومات الإصدار (`FileVersion` و`ProductVersion` و`ProductName` و`FileDescription` و`CompanyName` و`LegalCopyright` و`OriginalFilename` و`InternalName` و`Comments`). للمنصة `win32-x64` فقط.                                  |
| `--help`             | —                                               | طباعة الصيغة العامة.                                                                                                                                                                                                                 |
| `--version`          | —                                               | طباعة إصدار المترجم.                                                                                                                                                                                                                 |

يمكن أن يظهر كل خيار مرة واحدة باستثناء `--conditions`. راجع [الملفات التنفيذية لـ Windows](/ar/reference/windows-executables) لمعرفة صيغ الموارد.

## المدخلات والمخرجات

- المدخل ملف مصدري واحد بترميز UTF-8. والمدخل من نوع وحدة يجلب معه الوحدات التي يستوردها، والمدخل من نوع CommonJS الوحدات التي يطلبها عبر `require`، بما فيها حزم npm من `node_modules` ([حزم npm](/reference/npm))؛ أما الوحدات المدمجة `nona:*` و`node:*` فهي جزء من المترجم.
- يمكن أن يكون المدخل مجلد حزمة: يبني Nona الملف الذي يسمّيه الحقل `"bin"` في ملف `package.json` الخاص بها (الأمر الوحيد، أو الأمر الذي يحمل اسم الحزمة)، وإلا فالملف المذكور في `"main"` أو `index.js`.
- يُكتب الناتج في ملف مؤقت بجواره ثم يُعاد تسميته إلى مكانه، لذا لا يترك البناء الفاشل أبدًا ملفًا تنفيذيًا مكتوبًا جزئيًا ويحتفظ بالملف السابق.
- يرفض المترجم الكتابة فوق ملف المدخل، حتى عبر رابط صلب أو رمزي.
- تحصل مخرجات Linux على الصلاحيات `0755`.

## ذاكرة التخزين المؤقت لبيئة التشغيل

بيئة التشغيل والمقدمات المترجمة متطابقة لكل برنامج يربط الأجزاء نفسها، وتوليدها يستغرق معظم وقت البناء. يحفظها سطر الأوامر في مجلد للتخزين المؤقت، فتصبح عمليات البناء التالية أسرع بنحو ثلاث مرات (برنامج hello world على Linux: ‏1.1 ثانية ثم 0.33 ثانية). الناتج متطابق مع التخزين المؤقت أو بدونه. تخص المدخلات إصدارًا واحدًا من المترجم وتُتجاهل بعد التحديث.

| المتغير          | الأثر                                                                                                                                                              |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `NONA_CACHE_DIR` | مجلد التخزين المؤقت. الافتراضي: `%LOCALAPPDATA%\nona\cache` على Windows، و`~/Library/Caches/nona` على macOS، و`$XDG_CACHE_HOME/nona` أو `~/.cache/nona` في غيرهما. |
| `NONA_CACHE=0`   | عدم قراءة التخزين المؤقت أو الكتابة فيه.                                                                                                                           |

## التشخيصات ورموز الخروج

حالة الخروج `0` عند النجاح و`1` عند أي خطأ. تُطبع أخطاء المصدر هكذا:

```text
<file>:<line>:<column> <CODE>: <message>
```

| الرمز               | المعنى                                                                                                                                                                       |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `E_LEX` و`E_SYNTAX` | تعذّر تقسيم المصدر إلى رموز أو تحليله، أو أنه يستخدم صيغة غير مدعومة.                                                                                                        |
| `E_BIND`            | خطأ مبكر عُثر عليه أثناء حلّ الأسماء (تصريحات مكررة، وأهداف إسناد غير صالحة، وغيرها).                                                                                        |
| `E_MODULE`          | تعذّر حلّ وحدة أو قراءتها أو ربطها، أو أن التصديرات متعارضة.                                                                                                                 |
| `E_FFI_STATIC`      | استدعاء `define()` من `nona:ffi` ليس ثلاث سلاسل حرفية أو أن توقيعه غير صالح.                                                                                                 |
| `E_FFI_TARGET`      | تصريح DLL مترجَم للمنصة `linux-x64`، أو تصريح استدعاء نظام مترجَم للمنصة `win32-x64`.                                                                                        |
| `E_RESOURCE`        | أيقونة أو معلومات إصدار غير صالحة، أو موارد مطلوبة للمنصة `linux-x64`.                                                                                                       |
| `E_TARGET`          | منصة مستهدفة أو نظام فرعي غير مدعوم.                                                                                                                                         |
| `E_OPTION`          | خيار ترجمة غير صالح، مثل اسم جزء غير معروف في `--link`.                                                                                                                      |
| `E_HOST_MODULE`     | وحدة مدمجة (مثل `node:fs`) غير متاحة للهدف.                                                                                                                                  |
| `E_INTERNAL`        | خلل في المترجم وليس خطأ في البرنامج: فشل فحص داخلي في المرحلة التي تذكرها الرسالة (`parse`، `bind`، `lower`، `codegen`، `link`، …). يرجى الإبلاغ عنه مع البرنامج الذي يسببه. |

تُطبع أخطاء الوسائط بالشكل `nona: <message>`، مثل `Unknown option: --foo` و`Duplicate option: -o` و`Missing value for --target` و`Output is required (-o <output>)` و`Unsupported target: arm64` و`Unsupported subsystem: native` و`--subsystem requires --target win32-x64`.

## أمثلة

::: code-group

```sh [برنامج طرفي]
nona build app.js -o build/app.exe
```

```sh [برنامج رسومي مع موارد]
nona build app.mjs -o build/app.exe --subsystem windows --icon app.ico --version-info version.json
```

```sh [Linux]
nona build app.js -o build/app --target linux-x64
```

:::

## المترجم الأصلي

يضم كل [إصدار](https://github.com/40oleg/nona/releases/latest) الملف `nona` ملفًا تنفيذيًا أصليًا لكل منصة من [المنصات الأصلية](/reference/native-platforms) الثماني. بناه Nona نفسه، ولا يحتاج إلى Node.js، ويقبل الخيارات نفسها التي يقبلها `node dist/cli.js`. أما النسخة المستنسخة من المستودع فتشغّل مترجم TypeScript على Node.js 26. ويصف [دليل الإقلاع والتحقق](https://github.com/40oleg/nona/blob/main/docs/self-hosting.md) كيف يعيد المترجم الأصلي بناء نفسه.

لا تُترجَم تصريحات DLL في FFI إلا لمنصات Windows؛ أما تصريحات استدعاءات النظام الخام فتستخدم أرقام النواة الخاصة بالمنصة المختارة من Linux أو Darwin أو BSD (راجع [FFI](/ar/reference/ffi)).
