# حاسبة المصفوفات

يجمع [`examples/compat/matrix-calculator.cjs`](https://github.com/40oleg/nona/blob/main/examples/compat/matrix-calculator.cjs) مصفوفتين ويطرحهما ويضربهما، وينقل المصفوفة A، ويحسب محدد A ومعكوسها. ولا يستخدم إلا اللغة و`console.log`، لذا يعمل البرنامج نفسه على Node.js وكملف تنفيذي من Nona.

## البناء والتشغيل

::: code-group

```sh [Windows]
node dist/cli.js build examples/compat/matrix-calculator.cjs -o build/matrix-calculator.exe
.\build\matrix-calculator.exe
```

```sh [Linux]
node dist/cli.js build examples/compat/matrix-calculator.cjs -o build/matrix-calculator --target linux-x64
./build/matrix-calculator
```

:::

```text
A:
2  1
1  1
B:
3  4
5  6
Transpose A:
2  1
1  1
A + B:
5  5
6  7
…
```

## تغيير المدخلات

عدّل المصفوفتين في نهاية المصدر وأعد البناء:

```js
const A = [[2, 1], [1, 1]];
const B = [[3, 4], [5, 6]];
```

كل مصفوفة داخلية صف. يجب أن تكون المصفوفات غير فارغة ومستطيلة وتحتوي على أعداد منتهية. يتطلب الجمع والطرح أبعادًا متساوية؛ ويتطلب الضرب أن يساوي عدد أعمدة A عدد صفوف B؛ ويتطلب المحدد والمعكوس أن تكون A مربعة. ولا يوقف الخطأ في عملية ما العمليات الأخرى.

## الحسابات العددية

يُحسب المحدد والمعكوس بطريقة حذف غاوس-جوردان مع الارتكاز الجزئي بصيغة binary64. إذا لم يكن عنصر الارتكاز أكبر من `1e-12` مضروبًا في أكبر قيمة مطلقة في المدخلات، يُبلغ البرنامج بأن المحدد صفر وأنه لا يوجد معكوس. هذه عتبة عددية: قد ترفض مصفوفة سيئة التكييف قابلة للعكس في الحساب الدقيق.

## التحقق

```sh
node scripts/check-matrix-calculator.mjs
```

يترجم السكربت المثال ونسخة منه مع تأكيدات، ويشغّل الملفين التنفيذيين، ويقارن المخرج القياسي ومخرج الأخطاء ورموز الخروج بـ Node.js: نتائج العمليات، والمصفوفات المستطيلة، وتبديل الصفوف، والمصفوفات 1×1 و3×3، والمصفوفات المنفردة، وثمانية مدخلات غير صالحة.
