# Этап 0.13: Map и Set

Начата native реализация `Map`. Доступны конструктор с iterable, `size`, `set`, `get`, `has`, `delete`, `clear` и `forEach`. Записи хранятся в порядке добавления; удаление оставляет пустой узел, поэтому обход пропускает удалённые записи и видит добавленные во время обхода. Ключи сравниваются по SameValueZero, при сохранении `-0` нормализуется в `+0`. Вызов конструктора без `new` и вызовы методов с неверным receiver дают TypeError. Конструктор использует текущий метод `set` и закрывает итератор при ошибке добавления.

Узлы записей включены в точный GC: живые ключи и значения удерживаются Map, удалённые перестают трассироваться. Локальные Windows тесты **6/6**, целевой Linux native тест с GC stress прошёл. Test262: `Map.prototype.size` **9/11**, `get` **9/11**, `set` **12/14**, `forEach` **17/19**. Все оставшиеся отказы в этих четырёх группах используют ещё отсутствующие Set/WeakMap; результаты не доказывают полного соответствия Map.

Добавлены `Map.prototype.keys`, `values`, `entries` и `@@iterator` (алиас `entries`). Итератор сохраняет Map в корнях GC, пропускает удалённые записи, видит записи, добавленные после начала обхода, и остаётся завершённым после первого результата `done: true`. Целевые Windows и Linux native тесты прошли; `Map.prototype.entries` в Test262 — **8/10**, два отказа используют ещё отсутствующие Set/WeakMap.

После добавления итераторов полный локальный набор Map прошёл **8/8**. Регрессионный набор `for-of` после изменения общего `IteratorPrototype[Symbol.iterator]` прошёл **43/43**.

Добавлена native реализация `Set`: конструктор с iterable и IteratorClose при ошибке добавления, `size`, `add`, `has`, `delete`, `clear`, `forEach`, `keys/values/entries/@@iterator`, SameValueZero и трассировка записей и итераторов GC. `keys` и `@@iterator` ссылаются на ту же функцию, что и `values`. Windows тесты Set **8/8**, совместный набор Map+Set **16/16**, целевой Linux native тест с GC stress прошёл. Test262: группа конструктора `set-*` **12/12**, `values` **17/18**, `forEach` **32/33**; отказы в последних двух группах требуют `WeakSet`.

Добавлены `Map[Symbol.species]` и `Set[Symbol.species]`; обе группы Test262 прошли **4/4**. Остаётся полный аудит групп Map и Set. Этап 0.14 начат; см. `v0.14-weak-collections-status.md`.

Дополнительный прогон Test262 для `Set.prototype`: `add` **20/21**, `delete` **19/20**, `has` **29/30**, `clear` **18/19**, `entries` **16/17**, `keys` **1/1**, `size` **6/6**. Каждый отказ в первых пяти группах находится в тесте `does-not-have-setdata-internal-slot-weakset.js` и требует конструктора `WeakSet`; после его появления эти группы нужно повторить. Группы более поздних методов объединений множеств не входят в ES2020 и в этот прогон не включались.

Дополнительные группы `Set.prototype[Symbol.iterator]` и `[Symbol.toStringTag]` прошли по **1/1**. Первоначально `Set.prototype.constructor` упал **0/2**: статический прототип получал две записи fixup для поля списка свойств, а `@@toStringTag` не связывался с прежней цепочкой. Исправлена цепочка у `Set` и `Map`; повторный Test262 `Set.prototype.constructor` прошёл **2/2**, локальные проверки дескриптора и идентичности конструктора прошли для обеих коллекций; общий Windows регрессионный набор Map+Set **18/18**.

Полный прогон каталога Test262 `built-ins/Map` после реализации слабых коллекций: **164/204**. Из 40 отказов 37 относятся к более поздним `Map.groupBy`, `getOrInsert` и `getOrInsertComputed`; один требует `WeakRef`, один — `Reflect.construct`, один — cross-realm. В применимых тестах ES2020 этого каталога новых отказов не обнаружено.

Полный прогон каталога Test262 `built-ins/Set`: **229/383**. Из 154 отказов 151 относится к более поздним методам `difference`, `intersection`, `isDisjointFrom`, `isSubsetOf`, `isSupersetOf`, `symmetricDifference` и `union`. Остальные три файла требуют соответственно `Reflect.construct`, cross-realm и `WeakRef` (сверено с метаданными файлов). В применимых тестах ES2020 этого каталога новых отказов не обнаружено. Эти каталоги подтверждают реализованный поднабор Map/Set, но не заменяют проверку всего стандарта ES2020.
