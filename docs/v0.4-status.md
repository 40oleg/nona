# Nona v0.4.0: Array and numeric built-ins

Snapshot: 2026-09-26. This release extends the documented JavaScript subset;
it does not claim full ES2020 conformance. See the [support matrix](language-support.md),
the [ES2020 contract](es2020-contract.md), and the [release roadmap](release-roadmap-0.4-0.20.md).

## Added and corrected

- Completed the planned ES2020 Array method set for the current runtime types:
  `concat`, `flat`, `flatMap`, `sort`, `toLocaleString`,
  `Array.prototype[Symbol.unscopables]`, and the other Array methods added
  during 0.4 development. `Array.from`, `Array.of`, and `Array[Symbol.species]`
  are included in the audit.
- Implemented global `parseInt` and `parseFloat`, including their Number aliases.
- Corrected array iterator completion: an exhausted iterator remains done
  when its source array later grows.
- Added a short integer formatting path. Array algorithms no longer allocate
  a 4096-byte scratch buffer for every ordinary numeric index.

| Pinned positive Test262 smoke manifest | 100 pass, 0 fail, 0 skip. |
| Complete `built-ins/parseInt` and `built-ins/parseFloat` groups | 55/55 and 54/54. |
| Complete raw `built-ins/Array` group | 2640 pass, 352 fail, 90 skip of 3082. |

All 90 Array skips are `Array.fromAsync` tests, an API later than ES2020.
The 352 failures have recorded prerequisites in
[the per-file deferral list](v0.4-array-deferred.json): 150 target APIs introduced
after ES2020, 72 resizable-buffer cases, and 130 requiring later roadmap
features or the documented `eval` exception. A prerequisite may not be the
only issue in a test; each deferred case must be rerun when that prerequisite
is implemented. These raw counts are not a percentage of ES2020 coverage.

The five one-million-element sparse Array tests that timed out before the
formatting change now pass in about 0.4 seconds each on the local Windows host.
The 0.4 release gate covers the supported Array and numeric types; later
releases will add Date, RegExp, Proxy/Reflect, typed arrays, cross-realm
behavior, BigInt, async, modules, and the rest of the ES2020 contract.
