# Reflect и Proxy: этап 0.15

Срез: 28 сентября 2026 года. Этап не завершён.

Начат bootstrap объекта `Reflect` в native Windows/Linux программе. Добавлены тринадцать методов для обычных объектов: `apply`, `construct`, `defineProperty`, `deleteProperty`, `get`, `getOwnPropertyDescriptor`, `getPrototypeOf`, `has`, `isExtensible`, `ownKeys`, `preventExtensions`, `set`, `setPrototypeOf`. Методы не являются конструкторами и получают имя, длину и встроенное представление `Function.prototype.toString`; у объекта есть `Symbol.toStringTag` и стандартный дескриптор глобального свойства.

В закреплённом Test262 проверены корневые файлы `built-ins/Reflect` (3/3) и каталоги `apply` (8/9), `construct` (10/10), `defineProperty` (11/12), `deleteProperty` (10/11), `get` (11/11), `getOwnPropertyDescriptor` (12/13), `getPrototypeOf` (9/10), `has` (9/10), `isExtensible` (7/8), `ownKeys` (12/13), `preventExtensions` (8/10), `set` (18/18), `setPrototypeOf` (13/14). Всего **141/152** в этих каталогах. Десять отказов используют отсутствующий `Proxy`; один тест `apply/arguments-list-is-not-array-like-but-still-valid.js` использует исключённый динамический `Function`. Его независимый вариант с обычным объектом длины 1 прошёл.

`Reflect.construct` вызывает native constructor path с отдельным `new.target`, корректно обрабатывает вложенные bound-конструкторы и не разворачивает посторонний bound `newTarget` при выборе прототипа. Каталог `Function.prototype.bind` вырос с **94/100** до **97/100**; три оставшихся файла требуют cross-realm. Методы Reflect пока не перехватывают внутренние операции через Proxy. Полный каталог Reflect, инварианты Proxy, взаимодействия с массивами, typed arrays, функциями и cross-realm ещё не проверены. `defineProperty` предварительно преобразует ключ и снимок дескриптора до изменения цели, чтобы исключения пользовательского кода не превращались в `false`. Общий gate 0.15 остаётся открытым.

Одна и та же короткая программа с `ownKeys`, `has`, `get`, `set`, `deleteProperty` и `apply` выполнилась на Windows PE и Linux ELF через WSL Ubuntu. Программы с отдельным и связанным `newTarget` также прошли на обеих платформах. Выборочная локальная регрессия под Node.js 26.10.0 — **73/73**; полный локальный файл `function-bind.test.ts` — **27/27**. Системный Node.js 22 даёт ложный отказ в сравнении свойств обычной функции. Отдельный тест порядка ключей и тега Reflect — **1/1**. Конструктор проверен в режиме GC stress.

Позднее исправление: `Proxy` с собственным `construct` trap больше не читает `newTarget.prototype` до trap. При пересылке без trap receiver создаётся после проверки trap и возвращается как результат конструктора, включая вложенные Proxy. Проверены локальные Promise/Proxy GC stress тесты 23/23, Test262 `Proxy/construct` 18/29 (11 cross-realm отказов) и `Reflect/construct` 10/10, Linux native compatibility с отдельным примером Proxy 79/79. Общий gate этапа остаётся открытым.
