# BigInt: промежуточная проверка этапа 0.8

Срез: 27 сентября 2026 года. Работа ведётся в общей ветке `work/v0.6-v0.14`; отдельный релиз или PR для 0.8 не создаётся.

Реализованы BigInt literals, точная арифметика произвольной длины (`+`, `-`, `*`, `/`, `%`, `**`), побитовые операции, сдвиги, `++`/`--`, сравнения с Number, Boolean и String, явные преобразования `BigInt`/`Number`, `asIntN`/`asUintN`, методы прототипа и JSON TypeError. Строковый парсер принимает пробелы ES2020 и отклоняет U+180E. Большие целые binary64 преобразуются в BigInt по битам без потери точности.

| Проверка | Результат | Оставшиеся случаи |
| --- | --- | --- |
| Локальные BigInt тесты | 24/24, включая GC stress | Нет отказов в этом наборе |
| Test262 `built-ins/BigInt` | 75/77 | `is-a-constructor.js` требует Reflect.construct; `prototype/valueOf/cross-realm.js` требует другую realm |
| Test262 `language/expressions`, файлы с `bigint` в имени | 143/146 | Три теста logical assignment относятся к редакции после ES2020 |

| Полная локальная регрессия после Unicode whitespace | 1772 pass, 0 fail, 15 skip из 1787 | Отдельные проверки Linux и symlink пропущены средой; прогон включает начало работы над lexer RegExp |

Срезы Test262 используют закреплённую ревизию `7ab7fafa0003f73fc85c1b95d88094d33f7eb8bd`. Логи лежат в игнорируемом каталоге `work/`. Результаты выбранных групп не являются оценкой общего процента соответствия ES2020.

Добавлен воспроизводимый Linux x64 native тест произвольной арифметики BigInt, деления, остатка, `asIntN`, сравнения с Number и `BigInt.prototype.toJSON` в составе JSON.stringify. Он прошёл под WSL и совпал с Node.js. Отдельный Linux native сценарий для BigInt внутри JSON также прошёл. Общий gate 0.6–0.14 ещё открыт: полная интеграция RegExp, typed arrays и агентная модель Atomics не завершены; итоговый аудит 0.6–0.8 остаётся.
