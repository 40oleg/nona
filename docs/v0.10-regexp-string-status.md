# RegExp и String: этап 0.10

Срез: 27 сентября 2026 года. Работа идёт в общей ветке `work/v0.6-v0.14`; отдельного релиза или PR для 0.10 пока нет.

Добавлены `RegExp.prototype[Symbol.match]` и `String.prototype.match`. Первый метод использует `flags`, вызывает заменённый `exec`, обрабатывает глобальный поиск, пустые совпадения и продвижение по кодовым точкам при `u`; второй вызывает пользовательский `Symbol.match` у объекта либо создаёт RegExp из аргумента. Добавлены `RegExp.prototype[Symbol.search]` и `String.prototype.search`: сохраняется и восстанавливается `lastIndex`, пользовательский `Symbol.search` вызывается с нужным receiver. Добавлен `RegExp.prototype[Symbol.replace]`: захваты, именованные группы, callback и основные replacement patterns. Добавлен `RegExp.prototype[Symbol.split]`: sticky-копия, пустые совпадения, лимит и захваты; существующий `String.prototype.split` вызывает этот hook. Методы имеют неперечисляемые свойства прототипов; строковые методы неконструируемые.

Проверка Test262: `built-ins/RegExp/prototype/Symbol.match` — **53/53**, `built-ins/RegExp/prototype/Symbol.search` — **23/23**; `built-ins/String/prototype/match` — **47/51**, `built-ins/String/prototype/search` — **41/43**. `RegExp.prototype[Symbol.replace]` — **69/70**; один тест с удалёнными стандартными методами остаётся открытым. `String.prototype.replace` — **52/55**; два отказа используют исключённый динамический `Function`, один флаг `v` после ES2020. `RegExp.prototype[Symbol.split]` — **43/44**; один отказ требует cross-realm. `String.prototype.split` — **118/120**; два оставшихся файла используют исключённый `eval`. В `match` три оставшихся файла относятся к дублирующимся именам групп/флагу `v` после ES2020, ещё один использует исключённый `eval`. Два оставшихся файла `search` используют флаг `v`. Локальные целевые проверки RegExp, VM и строковых методов проходят.

Осталось завершить `matchAll`, `replaceAll`, оставшиеся Symbol hooks, а также случай удаления стандартных методов при замене. Полная интеграция 0.10 пока не объявлена.
