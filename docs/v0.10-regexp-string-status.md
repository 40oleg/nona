# RegExp и String: этап 0.10

Срез: 27 сентября 2026 года. Работа идёт в общей ветке `work/v0.6-v0.14`; отдельного релиза или PR для 0.10 пока нет.

Добавлены `RegExp.prototype[Symbol.match]` и `String.prototype.match`. Первый метод использует `flags`, вызывает заменённый `exec`, обрабатывает глобальный поиск, пустые совпадения и продвижение по кодовым точкам при `u`; второй вызывает пользовательский `Symbol.match` у объекта либо создаёт RegExp из аргумента. Добавлены `RegExp.prototype[Symbol.search]` и `String.prototype.search`: сохраняется и восстанавливается `lastIndex`, пользовательский `Symbol.search` вызывается с нужным receiver. Методы имеют неперечисляемые свойства прототипов; строковые методы неконструируемые.

Проверка Test262: `built-ins/RegExp/prototype/Symbol.match` — **53/53**, `built-ins/RegExp/prototype/Symbol.search` — **23/23** (последний отказ исправлен и отдельно перепроверен); `built-ins/String/prototype/match` — **47/51**, `built-ins/String/prototype/search` — **41/43**. В `match` три оставшихся файла относятся к дублирующимся именам групп/флагу `v` после ES2020, ещё один использует `eval`, исключённый из объёма проекта. Два оставшихся файла `search` используют флаг `v`. Локальные проверки RegExp, VM, match и search — **39/39**.

Осталось завершить `matchAll`, `replace`, `split`, `replaceAll`, остальные Symbol hooks и replacement patterns. Полная интеграция 0.10 пока не объявлена.
