# RegExp и String: этап 0.10

Срез: 27 сентября 2026 года. Работа идёт в общей ветке `work/v0.6-v0.14`; отдельного релиза или PR для 0.10 пока нет.

Добавлены `RegExp.prototype[Symbol.match]` и `String.prototype.match`. Первый метод использует `flags`, вызывает заменённый `exec`, обрабатывает глобальный поиск, пустые совпадения и продвижение по кодовым точкам при `u`; второй вызывает пользовательский `Symbol.match` у объекта либо создаёт RegExp из аргумента. Обе функции имеют неперечисляемые свойства прототипов. `String.prototype.match` реализован неконструируемым методом.

Проверка Test262: `built-ins/RegExp/prototype/Symbol.match` — **53/53**. Для `built-ins/String/prototype/match` после текущих исправлений проходят **47 из 51** файлов: три оставшихся относятся к дублирующимся именам групп/флагу `v` после ES2020, ещё один использует `eval`, исключённый из объёма проекта. Локальные проверки RegExp, VM и match — **38/38**.

Осталось завершить `matchAll`, `replace`, `search`, `split`, `replaceAll`, остальные Symbol hooks и replacement patterns. Полная интеграция 0.10 пока не объявлена.
