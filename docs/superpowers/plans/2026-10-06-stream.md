# Streams Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task by task.

**Goal:** Implement original stream APIs and connect process standard I/O to the canonical Events and Buffer implementations.

**Architecture:** Private Readable/Writable state machines share a prelude export object. Thin module providers and process adapters use the same constructors; an outer process tick helper schedules callbacks without constructing process metadata.

**Tech Stack:** TypeScript source generators, compiled JavaScript preludes, Node 26 source oracles and Nona native CI.

**Spec:** `docs/superpowers/specs/2026-10-06-stream-design.md`.

## Global constraints

- Original algorithms only; official API documentation and Node 26 black-box oracles.
- Exactly two prelude globals; private helpers attach to `__nonaRegexpVm`.
- No generated executables run locally. Compile/link all eight supported targets in memory.
- One issue/branch/PR: issue #141. Owner identity and English documentation.
- Coordinate shared compiler flags, Events integration and process stdio with their owners.

## Review focus

- Synchronous callbacks followed by another write must preserve queue pressure and callback ordering.
- Destroy or abort during a pending operation must complete callbacks exactly once and preserve error identity.
- Paused input with multiple pipe destinations must resume only after every required drain.
- Split multibyte characters and sliced byte views must preserve bytes and decoder state.
- Public prototype mutation and subclass hooks must not corrupt private queue bookkeeping.
