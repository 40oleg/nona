# Матричный калькулятор

Исходник: [matrix-calculator.cjs](../examples/compat/matrix-calculator.cjs).
Пример выполняет сложение, вычитание, умножение, транспонирование A,
вычисление определителя и обратной матрицы A. Результаты печатаются в консоль.

## Как собрать самостоятельно

В PowerShell, на Windows x64 с установленными Node.js и npm:

```powershell
cd C:\Users\helgus\projects\nona
npm.cmd run build
node .\dist\cli.js build .\examples\compat\matrix-calculator.cjs -o .\build\matrix-calculator.exe --target win32-x64
.\build\matrix-calculator.exe
```

В текущей рабочей папке зависимости уже установлены. В новой копии проекта
сначала выполните `npm.cmd ci`. Node.js нужен для сборки компилятора и запуска
его CLI; полученный EXE работает самостоятельно.

## Как изменить вычисления

В конце исходника измените массивы `A` и `B`, например:

```javascript
const A = [[2, 1], [1, 1]];
const B = [[3, 4], [5, 6]];
```

Каждый вложенный массив — строка. После изменения повторите команду
`node .\dist\cli.js build ...` из инструкции и запустите EXE.
Повторная сборка самого компилятора через npm нужна только при изменении его кода.
Ввод с клавиатуры и аргументы командной строки в этом примере не используются.

Матрицы должны быть непустыми, прямоугольными, с конечными числовыми элементами.
Сложение и вычитание требуют одинакового размера; умножение — равенства числа
столбцов A числу строк B. Определитель и обратная матрица требуют квадратной A.
Ошибка одной операции не препятствует выполнению следующих операций.

Используется метод Гаусса — Жордана с выбором максимального по модулю ведущего
элемента в столбце. Вычисления приближённые (binary64). Если ведущий элемент
не превышает `1e-12` от максимального модуля исходных элементов, пример сообщает
нулевой определитель и отсутствие обратной матрицы. Это численный порог:
он может отклонить плохо обусловленную, но математически обратимую матрицу.
Очень большие или малые значения могут вызвать переполнение или потерю точности.

## Проверка

```powershell
node .\scripts\check-matrix-calculator.mjs
```

Проверка компилирует пример и вариант с проверочными утверждениями, запускает
оба EXE и сравнивает stdout, stderr и коды завершения с Node.js.
Проверяются результаты операций, прямоугольные матрицы, перестановка строк,
матрицы 1×1 и 3×3, вырожденность, сохранность исходной матрицы и восемь
некорректных входов. На 2026-09-23 обе программы прошли проверку.
