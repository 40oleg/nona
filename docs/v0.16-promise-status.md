# 0.16 Promise и очередь jobs — текущий срез

Добавлена очередь Promise jobs, которая исполняется после пользовательского `main` до завершения Windows/Linux процесса. Начальная реализация включает конструктор, resolving functions, thenable assimilation, `then`, `catch`, `finally`, `resolve`, `reject`, `all`, `allSettled` и `race`. Состояние Promise хранится во внутреннем WeakMap. Обработчики вызываются из очереди; новые jobs продолжают выполняться до её опустошения.

Проверка: четыре локальных native GC stress теста Promise с точным сравнением вывода с Node.js 26; совокупный набор Promise/Proxy/Reflect перед последним тестом — 18/18. Отдельный Linux ELF smoke Promise совпал с Node.js 26; набор Linux compat — 77/77. Runner Test262 теперь принимает `TEST262_RUN_ASYNC=1`, ждёт обработки jobs в standalone программе и требует ровно одного успешного `$DONE`. Результаты выбранных каталогов Windows с включённым async режимом:

| Каталог | Pass | Fail | Skip |
| --- | ---: | ---: | ---: |
| `Promise` root (direct only) | 57 | 1 | 0 |
| `Promise/resolve` | 29 | 1 | 0 |
| `Promise/reject` | 14 | 1 | 0 |
| `Promise/prototype/then` | 75 | 0 | 0 |
| `Promise/prototype/finally` | 29 | 0 | 0 |
| `Promise/all` | 97 | 1 | 0 |
| `Promise/allSettled` | 103 | 1 | 0 |
| `Promise/race` | 93 | 1 | 0 |

Один fail в каждом из пяти каталогов `resolve`, `reject`, `all`, `allSettled`, `race` — `ctx-non-ctor.js`, использующий ранее исключённый динамический `eval`. Исправлены вызов inherited setter `Array.prototype[0]` внутренними массивами Promise и наблюдаемая длина/конструируемость callbacks `finally`.

Исправлен порядок проверки executor и `newTarget.prototype` для `Reflect.construct(Promise, args, newTarget)` и обычного прямого `new Promise(...)`, включая развёрнутые аргументы. Корневой Test262 повторно дал 57/58; локальные тесты сравнивают результат с Node.js 26 при GC stress. Внутренняя функция запуска очереди не видна пользовательскому коду. Linux native compatibility с новым примером Promise: 78/78.

Вложенные bound-конструкторы Promise теперь выбирают первый аргумент из самой внутренней привязки до получения прототипа `newTarget`; проверены `new` и `Reflect.construct` под GC stress. Снова прошли 26/26 локальных тестов Promise и конструкторов, корневой Test262 — 57/58, Linux native compatibility с bound Promise — 78/78.

Проверены оставшиеся каталоги metadata: `Promise/prototype/catch` 14/14, `Promise/Symbol.species` 5/5, прямые файлы `Promise/prototype` 6/6. Getter `@@species` теперь имеет стандартное имя, не является конструктором и возвращает native-представление; `Promise.prototype` имеет `writable: false`. Локальные Promise GC stress тесты 9/9; корневой Test262 по-прежнему 57/58; Linux native compatibility с проверкой metadata 79/79.

Прозрачные Proxy обёртки конструктора Promise теперь проверяют эффективный
executor до чтения `newTarget.prototype`, включая вложенный Proxy, прямой
`new` и bound Promise. Proxy с ловушкой `construct` сохраняет собственный
порядок операций. Локальный тест сравнен с Node.js 26 под GC stress.

Этап **не закрыт**: в корневом каталоге остаётся cross-realm. Не завершены политика необработанных отклонений и проверка всех наследуемых/изменяемых intrinsics. Требуется gate остальных групп Promise и связанных language тестов на Windows/Linux. Указанные результаты относятся к выбранным каталогам, а не к общему проценту ES2020.

Полный рекурсивный каталог Test262 `built-ins/Promise` с async-режимом:
**530/732**. Из 202 отказов 196 относятся к API после ES2020:
`any` (92), `allKeyed` (44), `allSettledKeyed` (43), `try` (13),
`withResolvers` (4). Пять оставшихся `ctx-non-ctor.js` в `all`,
`allSettled`, `race`, `reject`, `resolve` используют исключённый `eval`;
`proto-from-ctor-realm.js` требует другую realm. В применимых завершившихся
тестах ES2020 новых независимых отказов не обнаружено. Общий gate 0.16
остаётся открытым по причинам выше и до аудита language/job semantics.

Дополнение 28.09.2026: внутренний WeakMap состояния Promise теперь сохраняет
исходные методы `get`/`set` при bootstrap, поэтому изменение пользователем
`WeakMap.prototype` не ломает уже созданные и новые Promise. Политика host для
необработанного отклонения задана явно: после опустошения очереди jobs первое
Promise, для которого не вызван `then`, приводит к ошибке standalone процесса;
обработчик, добавленный последующим job, предотвращает её. Локальный набор
Promise с GC stress прошёл **13/13** до добавления отдельной проверки причины
`undefined`. Повтор Test262 и Linux native после этой правки ещё нужен.
