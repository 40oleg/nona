# 0.16 Promise и очередь jobs — текущий срез

Добавлена очередь Promise jobs, которая исполняется после пользовательского `main` до завершения Windows/Linux процесса. Начальная реализация включает конструктор, resolving functions, thenable assimilation, `then`, `catch`, `finally`, `resolve`, `reject`, `all`, `allSettled` и `race`. Состояние Promise хранится во внутреннем WeakMap. Обработчики вызываются из очереди; новые jobs продолжают выполняться до её опустошения.

Проверка: четыре локальных native GC stress теста Promise с точным сравнением вывода с Node.js 26; совокупный набор Promise/Proxy/Reflect перед последним тестом — 18/18. Отдельный Linux ELF smoke Promise совпал с Node.js 26; набор Linux compat — 77/77. Runner Test262 теперь принимает `TEST262_RUN_ASYNC=1`, ждёт обработки jobs в standalone программе и требует ровно одного успешного `$DONE`. Результаты выбранных каталогов Windows с включённым async режимом:

| Каталог | Pass | Fail | Skip |
| --- | ---: | ---: | ---: |
| `Promise` root (direct only) | 56 | 2 | 0 |
| `Promise/resolve` | 29 | 1 | 0 |
| `Promise/reject` | 14 | 1 | 0 |
| `Promise/prototype/then` | 75 | 0 | 0 |
| `Promise/prototype/finally` | 29 | 0 | 0 |
| `Promise/all` | 97 | 1 | 0 |
| `Promise/allSettled` | 103 | 1 | 0 |
| `Promise/race` | 93 | 1 | 0 |

Один fail в каждом из пяти каталогов `resolve`, `reject`, `all`, `allSettled`, `race` — `ctx-non-ctor.js`, использующий ранее исключённый динамический `eval`. Исправлены вызов inherited setter `Array.prototype[0]` внутренними массивами Promise и наблюдаемая длина/конструируемость callbacks `finally`.

Этап **не закрыт**: в корневом каталоге один fail связан с порядком проверки executor и `newTarget.prototype`, второй — cross-realm. Не завершены политика необработанных отклонений, проверка всех наследуемых/изменяемых intrinsics и защита внутренней точки drain от пользовательского кода. Требуется gate остальных групп Promise и связанных language тестов на Windows/Linux. Указанные результаты относятся к выбранным каталогам, а не к общему проценту ES2020.
