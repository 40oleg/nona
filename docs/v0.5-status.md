# Nona 0.5 — статус проверки

Срез: 26 сентября 2026 года. Ветка `work/v0.5.0` развивается от опубликованного
0.4.0. Критерий релиза задан в [плане 0.4–0.20](release-roadmap-0.4-0.20.md).
Релиз ещё не опубликован; ветка подготовлена для отдельного pull request.

## Реализовано

- Независимые от RegExp методы String: `fromCodePoint`, `raw`, `concat`,
  `toUpperCase`, `toLowerCase`, `toLocaleUpperCase`, `toLocaleLowerCase`,
  `normalize`, `localeCompare`; строковые ветки `split` и `replace`.
  Нормализация использует закреплённые таблицы Unicode 17 и поддерживает
  NFC, NFD, NFKC и NFKD. `localeCompare` использует порядок C locale после
  NFC и распознаёт каноническую эквивалентность.
- `Number.prototype.toFixed`, `toExponential`, `toPrecision`,
  `toLocaleString`. Без ECMA-402 последний использует формат C locale;
  зарезервированные аргументы игнорируются.
- Все методы Math редакции ES2020, включая тригонометрию, логарифмы,
  экспоненты и гиперболические функции.
- Глобальные `encodeURI`, `encodeURIComponent`, `decodeURI`,
  `decodeURIComponent`.

Отдельно проверен Linux native `Number.prototype.toLocaleString` с числом
1234.5 и C locale. Пробы Linux, пропущенные массовым запуском, повторяются
отдельно и прошли; совместимые Linux примеры 77/77 прошли.
Числа Test262 относятся к закреплённой ревизии
`7ab7fafa0003f73fc85c1b95d88094d33f7eb8bd`, а не к общей доле
поддержки ES2020. Группы RegExp/String перенесены в 0.10, BigInt — в 0.8,
Date — в 0.7, Reflect — в 0.15, семантика `with` и исключённых
`eval`/динамических конструкторов функций — в 0.19, cross realm — в 0.20.
Методы `at`, `replaceAll`, `isWellFormed`, `toWellFormed`, `Math.f16round` и
`Math.sumPrecise` появились после ES2020 и не входят в контракт релиза.

Команды локального gate: `npm run build`, `npm test`, `npm run compare`,
`npm run compare:linux`, `node scripts/test262-smoke.mjs` и запуск того же
адаптера с путями `built-ins/String`, `built-ins/Number`, `built-ins/Math`
и группами глобальных функций. Новые операции проверены также при GC stress,
а нормализация — на официальном Unicode NormalizationTest 17.
