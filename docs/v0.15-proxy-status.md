# Proxy: этап 0.15

Срез: 28 сентября 2026 года. Этап не завершён.

В native runtime добавлен отдельный объект Proxy с target, handler и признаком отзыва. GC трассирует оба значения. Конструктор проверяет объектность аргументов и требование `new`; связанная функция даёт стандартное отсутствие собственного `prototype`. `Proxy.revocable` создаёт отзыватель, после отзыва доступ через прокси бросает `TypeError`.

Общие пути `Get` и `HasProperty` теперь вызывают ловушки `get` и `has` с target, ключом и receiver там, где он требуется; при отсутствии ловушки операция пересылается цели. Для обычной цели `get` проверяет значение собственного non-configurable/non-writable свойства и отсутствие getter у собственного non-configurable accessor. `has` запрещает скрывать собственное non-configurable свойство, а также собственное свойство нерасширяемой цели. `Reflect.get(proxy, key)` без отдельного receiver и `Reflect.has(proxy, key)` проходят через ловушки.

Закреплённый Test262: корневые файлы `built-ins/Proxy` **24/28**, `get` **14/19**, `has` **10/26**, `revocable` **16/18**. Два инвариантных теста `get` прошли после исправления. Из оставшихся отказов часть требует callable Proxy, cross-realm и `with`/наследования; три файла `get` проверяют receiver и пересылку через вложенные прокси. Каталоги `Reflect/get` и `Reflect/has` после изменения — **11/11** и **10/10**. Native Windows тест с принудительным GC — **1/1**; короткие программы с ловушками, отзывом и инвариантом `has` прошли на Linux ELF через WSL.

Остальные внутренние методы Proxy (`set`, дескрипторы, `apply`, `construct`) пока не подключены. Инварианты `get` и `has` для exotic и вложенной Proxy-цели, передача receiver через обычную цель и унаследованный Proxy ещё открыты. Полный каталог из 311 файлов и интеграция с Reflect остаются в gate 0.15.

Дополнение: подключён Proxy [[Delete]] / deleteProperty для обычной цели, включая пересылку при отсутствии trap и инварианты собственного non-configurable свойства и нерасширяемой цели. Test262 Proxy/deleteProperty: 15/17; остаются cross-realm и вложенный Proxy. Native GC stress и Linux ELF smoke прошли. Каталог Reflect/deleteProperty: 11/11.

Подключён Proxy [[IsExtensible]] / isExtensible, включая вложенную Proxy-цель и сверку результата ловушки с состоянием цели. Test262 Proxy/isExtensible: 11/12; оставшийся случай cross-realm. Native GC stress и Linux ELF smoke прошли.

Подключён Proxy [[PreventExtensions]] / preventExtensions: ловушка, пересылка цели, проверка результата true и различие Object/Reflect при false. Test262 Proxy/preventExtensions: 10/12 (1 cross-realm отказ, 1 пропуск); Reflect/preventExtensions: 10/10. Native GC stress и Linux ELF smoke прошли.

Подключён Proxy [[GetPrototypeOf]] / getPrototypeOf, включая вложенные цели, инвариант нерасширяемой цели и путь instanceof. Test262 Proxy/getPrototypeOf: 18/19 (cross-realm остаётся); Reflect/getPrototypeOf: 10/10. Native GC stress и Linux ELF smoke прошли.

Подключён Proxy [[SetPrototypeOf]] / setPrototypeOf, включая пересылку вложенной цели, инвариант нерасширяемой цели и булев результат Reflect без перехвата TypeError от ловушки. Test262 Proxy/setPrototypeOf: 16/17 (cross-realm остаётся); Reflect/setPrototypeOf: 14/14. Native GC stress и Linux ELF smoke прошли.

Общий getProperty сохраняет исходный receiver при пересылке через вложенные Proxy; Reflect.get с явным receiver использует native путь. Прямой и вложенный вызовы getter прошли GC stress; Reflect/get — 11/11. Путь унаследованного Proxy ещё открыт (Proxy/get: 14/19). Исправлено восстановление ключа в обычном deleteProperty, из-за которого удаление индексного свойства строки аварийно завершалось; Proxy/deleteProperty теперь 16/17. Выборочный регрессионный прогон дал 162/163, затем единственный упавший тест строки перепроверен отдельно и прошёл. Шесть Proxy GC stress тестов и Linux ELF smoke прошли. Полный регрессионный gate ещё открыт.

Общий путь get/has проверяет обычные собственные свойства до первого Proxy в цепочке прототипов, затем вызывает соответствующую ловушку с исходным receiver для get. Test262 Proxy/get: 18/19 (cross-realm); Proxy/has: 16/26 (девять with compile failures и один cross-realm). Семь локальных Proxy тестов с GC stress, Linux ELF smoke и 42 регрессионных теста object-introspection/property-descriptors прошли. Прочие операции с унаследованным Proxy ещё требуют отдельного gate.

Подключён Proxy [[OwnPropertyKeys]] / ownKeys с CreateListFromArrayLike для строк и символов, проверкой дубликатов, собственных non-configurable ключей и точного набора ключей нерасширяемой обычной цели. Reflect.ownKeys теперь сохраняет порядок trap через native список. Test262 Proxy/ownKeys: 25/27 (оба оставшихся — cross-realm), Reflect/ownKeys: 13/13. Вложенный Proxy без ownKeys trap пересылается цели; инварианты вложенной Proxy-цели с собственным trap и getOwnPropertyDescriptor trap ещё открыты. Восемь Proxy GC stress тестов, Linux ELF smoke и 107 тестов object collections/introspection/integrity прошли.

Подключён Proxy [[GetOwnProperty]] / getOwnPropertyDescriptor: пересылка без ловушки, преобразование и дополнение дескриптора, проверка инвариантов отсутствующего и несовместимого свойства. Object.keys и инварианты ownKeys теперь читают дескриптор вложенной Proxy-цели. Test262 Proxy/getOwnPropertyDescriptor: 15/21; три оставшихся сценария используют вложенную Proxy-цель, два — cross-realm, один требует Proxy [[Set]]. Reflect/getOwnPropertyDescriptor: 13/13; девять локальных Proxy GC stress тестов и 89 тестов дескрипторов/интроспекции/коллекций прошли. Linux ELF smoke прошёл. Полный gate и оставшиеся ловушки открыты.
