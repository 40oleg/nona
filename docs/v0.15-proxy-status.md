# Proxy: этап 0.15

Срез: 28 сентября 2026 года. Этап не завершён.

В native runtime добавлен отдельный объект Proxy с target, handler и признаком отзыва. GC трассирует оба значения. Конструктор проверяет объектность аргументов и требование `new`; связанная функция даёт стандартное отсутствие собственного `prototype`. `Proxy.revocable` создаёт отзыватель, после отзыва доступ через прокси бросает `TypeError`.

Общий путь `Get` теперь вызывает ловушку `get` с target, ключом и receiver, если ловушка присутствует; при отсутствии ловушки чтение пересылается цели. Для обычной цели проверяются два инварианта: значение собственного non-configurable/non-writable свойства и отсутствие getter у собственного non-configurable accessor. `Reflect.get(proxy, key)` без отдельного receiver тоже проходит через ловушку.

Закреплённый Test262: корневые файлы `built-ins/Proxy` **24/28**, `get` **14/19**, `revocable` **16/18**. Два инвариантных теста `get` прошли после исправления. Из оставшихся отказов часть требует callable Proxy и cross-realm; три файла `get` проверяют receiver и пересылку через вложенные прокси. Каталог `Reflect/get` после изменения — **11/11**. Native Windows тест с принудительным GC — **1/1**; короткая программа с ловушкой и отзывом прошла на Linux ELF через WSL.

Остальные внутренние методы Proxy (`set`, `has`, `deleteProperty`, `ownKeys`, дескрипторы, прототип, extensibility, `apply`, `construct`) пока не подключены. Инварианты `get` для exotic и вложенной Proxy-цели, передача receiver через обычную цель и унаследованный Proxy ещё открыты. Полный каталог из 311 файлов и интеграция с Reflect остаются в gate 0.15.
