# RegExp: начало этапа 0.9

Срез: 27 сентября 2026 года. Работа идёт в общей ветке `work/v0.6-v0.14`, без отдельного PR.

Лексер различает `/` как деление и начало литерала RegExp в основных контекстах выражения, учитывает экранирование и символьные классы, проверяет флаги ES2020 `gimsuy`. Парсер создаёт отдельный AST-узел с шаблоном и флагами; binder его принимает. Пока native runtime RegExp не готов, компилятор возвращает явную диагностику `E_UNSUPPORTED` для такого литерала.

Проверка: frontend 45/45; общая native-регрессия после изменения лексера 1772 pass, 0 fail, 15 skip из 1787. Контекстная неоднозначность `/` в отдельных грамматических случаях и точная проверка Unicode-паттернов остаются открытыми. Constructor, исполнение, `lastIndex` и String-интеграция ещё не реализованы.
