# Nona Windows x64 AOT Compiler Implementation Plan

**Итог исполнения 2026-09-20:** задачи 1–11 реализованы. `npm.cmd run check`:
148 тестов, 147 PASS, 0 FAIL, 1 SKIP (Windows не разрешает создание symlink).
Все четыре примера собраны и запущены с кодом 0. Независимое ревью backend,
CLI, ABI, вывода и числового runtime завершено; найденная проверка rel32 RVA
исправлена с regression test. Ниже сохранён исходный пошаговый план; его
checkbox отражают состояние документа до исполнения. Фактические результаты
и технические решения записаны в `.superpowers/sdd/js-aot-win64/progress.md`.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Создать компилятор согласованного поднабора ES5 в самостоятельные Windows x64 executable.

**Architecture:** TypeScript реализует lexer, parser, binder, IR, x64 emitter и PE writer. Runtime также генерируется собственным emitter и входит в executable. Внешний компилятор, ассемблер, CRT и интерпретатор не используются.

**Tech Stack:** Node.js, TypeScript, node:test, Windows x64, PE32+, SSE2, KERNEL32.dll.

**Spec:** [2026-09-20-js-aot-win64-design.md](../specs/2026-09-20-js-aot-win64-design.md). Документ одобрен пользователем; перед исполнением прочитать целиком.

## Global Constraints

- «Согласованы Windows x64, собственный генератор машинного кода и PE32+, а также TypeScript для самого компилятора».
- «Это ограниченный поднабор ES5, а не реализация всего стандарта».
- «Поддерживаемые операции сохраняют семантику JavaScript».
- «Node.js нужен для запуска компилятора, TypeScript — для его разработки и сборки».
- «Ключ `-o` обязателен. Вход — один файл UTF-8, без модулей и подключения файлов».
- «Числа — IEEE 754 binary64, включая `NaN`, бесконечности и отрицательный ноль».
- «В v0.1 нет сборщика мусора: арена освобождается при завершении».
- «Он не использует CRT, JIT или интерпретатор».
- «Выравнивания: FileAlignment 0x200, SectionAlignment 0x1000».
- «Работа считается завершённой после выполнения этих проверок с реально запущенными Windows-executable».
- Никаких дополнительных языковых возможностей вне раздела 3 спецификации.
- Входной каталог не является Git-репозиторием. Коммиты делать только если к моменту исполнения репозиторий появился; отсутствие Git не мешает реализации и проверкам.

## Review Focus

1. Вложенные вызовы в аргументах: результат первого аргумента не должен перезаписываться следующим вызовом; задача 7.
2. Алиасы входного и выходного пути, включая регистр и hard links: исходник нельзя затереть; задача 10.
3. Частичная запись stdout, закрытый pipe и недоступный stderr: конечный код ошибки без бесконечного повтора; задача 4.
4. Большие стековые кадры и выход rel32 за диапазон: probing или понятная диагностика вместо повреждения памяти; задачи 2 и 7.
5. `console.log("%s", "x")` и `console.log(-0)`: собственный контракт вывода, а не format-string и inspect-семантика Node.js; задачи 4 и 9.

Исходники в `src`, тесты в `tests`, примеры в `examples`. Скомпилированные

## Task 6: IR и нативное управление потоком

`src/compiler.ts`, `tests/control-flow.test.ts`.

**Interfaces:** `lower(bound: BoundProgram): ModuleIR`,
`generate(module: ModuleIR): NativeProgram`. `ModuleIR` содержит globals,

loadGlobal, storeGlobal, unary, binary, call; terminators: jump, branch, return.

`compile` реализует публичный контракт в начале плана.
