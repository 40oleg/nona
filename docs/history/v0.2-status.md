# Nona v0.2: таблица полноты реализации

Срез на 26 сентября 2026 года. «Частично» означает, что реализован и проверен только перечисленный поднабор; это не процент соответствия ES2020.

| Область | Состояние | Что подтверждено / основной пробел |
| --- | --- | --- |
| Инфраструктура компилятора и GC | Частично | Есть frontend/IR, runtime и набор тестов; полный набор семантики ES2020 ещё не закрыт. |
| Выпуск исполняемых файлов Windows x64 | Работает для поддерживаемого поднабора | Генерируется PE; 42/42 совместимых примера совпали с Node.js 26. |
| Лексика, области видимости, выражения и операторы | Частично | Базовый поднабор работает; полное покрытие языка и Test262 отсутствует. |
| Циклы `for...in` и `for...of` | Частично | Есть `var`/`let`/`const`, захваты по итерациям и IteratorClose; Test262: 85/119 и 142/751 соответственно. |
| Функции, стрелки, rest и шаблонные строки | Частично | Есть стрелки, `...rest`, шаблоны без тегов; нет default/destructuring parameters, spread и tagged templates. |
| Объекты, дескрипторы и Symbol | Частично | Есть примитив Symbol, реестр, символьные ключи и часть well-known symbols; Symbol Test262: 72/98. |
| Итераторы | Частично | Есть общий синхронный протокол, IteratorClose и итераторы массивов, строк, `arguments`; генераторов нет. |
| Классы и наследование | В основном отсутствует | Полная семантика классов не реализована. |
| Стандартная библиотека | Частично | Добавлены отдельные методы Array, String, Math и Number; большинство API ещё отсутствует. |
| BigInt, RegExp, коллекции | Отсутствует | Нет BigInt, RegExp, Map/Set и слабых коллекций. |
| Буферы, типизированные массивы, Atomics | Отсутствует | Требуются ArrayBuffer, typed arrays и Atomics. |
| Proxy и Reflect | Отсутствует | Требуется реализация метаопераций. |
| Promise, очереди задач и async | Отсутствует | Нет Promise/jobs, async functions и async iterators. |
| Модули | Отсутствует | Нет разбора, связывания и загрузки модулей ES. |
| Proper tail calls и Annex B | Отсутствует или частично | Требуется отдельная проверка и реализация оставшихся случаев. |
| Linux native | Отсутствует | Есть проверка frontend/IR в Linux CI; ELF/SysV backend и перенос runtime ещё нужны. |

Проверка текущего поднабора: 1223 успешных теста из 1224 (1 пропуск из-за права на symlink, 0 ошибок); положительный smoke-набор Test262 — 22/22. Эти результаты относятся к выбранным тестам и не являются оценкой общего процента реализации ES2020.
