# Nona v0.6.0 — release status

Release date: 2026-09-30. This experimental subset release integrates
[PR #5](https://github.com/40oleg/nona/pull/5) on top of v0.5.0. The milestone
numbers in the roadmap describe areas of work; this consolidated release
does not certify those milestones or the full ES2020 contract as complete.

## Included work

- Date and JSON, BigInt, RegExp and its String integrations.
- ArrayBuffer, DataView, typed arrays, SharedArrayBuffer and Atomics agents.
- Map, Set, weak collections, Proxy, Reflect, Promise jobs and rejection handling.
- Async functions/generators/iteration, modules and dynamic imports, `with`,
  realm support, tail calls, and language/Annex B corrections within the
  documented implementation limits.
- Native Windows x64 PE and Linux x64 ELF coverage and a cached
  runtime/prelude image during code generation.

## Verification and limitations

The [2026-09-30 Test262 audit](pr5-es2020-remaining-work.md) records Linux
language 16,514/17,337, built-ins 15,245/15,416, and Atomics agents 268/268
passing; Windows records language 16,516/17,337, built-ins 15,433/15,554,
and Atomics agents 268/268 passing. These are dated catalog snapshots at
the commits specified in that report, with classified exclusions and
subsequent targeted fixes. They are not overall ES2020 conformance scores.

Release preparation on Windows x64 uses Node.js 26.9.0 (the same version
as CI). The build passed, and all 10 targeted sort/CLI tests passed without
skips. Two pre-existing sort tests were reproduced failing before the
correction: they required Node's exact comparison call count. The updated
tests verify the sorted result, mutation and getter/comparator/setter order
with any positive comparison count, and keep `undefined` out of callbacks.
The runtime sorting algorithm is unchanged.

Release verification commands are `node scripts/build.mjs`,
`node --test dist/tests/*.test.js`, `node scripts/compare-examples.mjs`,
and the Windows/Linux jobs in `.github/workflows/check.yml`, including the
pinned Test262 smoke and built-in suites. The GitHub release notes record
the final results for the tagged revision.

Known limits include runtime dynamic `eval`/source-constructor exceptions,
cross-realm defaults for some constructors implemented in the JS prelude,
a remaining TypedArray constructor ordering case, large-array performance
timeouts, and documented Annex B differences. Node.js APIs, browser APIs,
and ECMA-402 internationalization are outside the runtime target.

See the [support matrix](../language-support.md),
[remaining audit items](pr5-es2020-remaining-work.md), and
[completion contract](../es2020-contract.md) before relying on a feature.
