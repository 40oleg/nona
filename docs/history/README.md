# Documentation history

Snapshots that were written for a particular release or agent session. They are kept for context, but they describe the project as it was at the time and may contradict the current code. For the current state read [`../status.md`](../status.md), [`../roadmap.md`](../roadmap.md) and the reference pages in [`../`](../README.md).

| Group | Files |
| --- | --- |
| Per-release status | `v0.2-status.md` ... `v0.16-promise-status.md` (the current status is `../status.md`) |
| Deferred Test262 lists | `v0.4-array-deferred.json`, `v0.5-number-deferred.json`, `v0.5-string-deferred.json` |
| Plans and audits | `release-roadmap-0.4-0.20.md`, `pr5-es2020-remaining-work.md`, `runtime-operations-audit.md` |
| Logs | `development-log.md` (Russian), `continuation-checkpoint.md` |
| Agent plans and specs | `superpowers/` |

`../status.md` is rewritten for each release instead of adding a new `vX-status.md`; the per-release details belong in `CHANGELOG.md`.
