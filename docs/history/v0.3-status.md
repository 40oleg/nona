# Nona v0.3.0: implementation status

Snapshot: 2026-09-26. This is a development release of a JavaScript subset, not a claim of ES2020 conformance. The detailed [support matrix](../language-support.md) and [completion contract](../es2020-contract.md) remain authoritative.

| Area | Status in v0.3.0 |
| --- | --- |
| Windows x64 native output | PE32+ for the documented subset; native regression suite and Node.js comparisons. |
| Linux x64 native output | ELF64 and direct syscalls for the same subset; compatible programs compared with Node.js under WSL. GitHub CI is configured, with its first remote run pending. |
| Language and runtime | Default/destructuring parameters, spread, tagged templates, basic classes/inheritance, generators and `yield*`, plus earlier iteration and Symbol support. Each remains limited by the support matrix. |
| Standard library | Selected Math, String, Array, Number, Object, Symbol, and global methods. Most ECMA-262 APIs remain unimplemented. |
| GC | Precise nonmoving mark/sweep; generator stacks and callback roots have stress tests. Weak collections and async roots remain. |

Major remaining work includes BigInt, RegExp, Date, JSON, collections and weak collections, ArrayBuffer and typed arrays, Atomics, Proxy/Reflect, Promise/jobs, async functions and iteration, ES modules, `with`, proper tail calls, more Annex B cases, and the remaining standard-library and language edge cases. `eval` and dynamic Function constructors are documented project exceptions.

Test counts are for selected native tests and Test262 groups, not a percentage of the ES2020 specification. The exact release-gate results are recorded in the [development log](development-log.md).

Local release checks with Node.js 26.10.0: 1437 native tests, 1430 passed, 0 failed, 7 skipped (one Windows symlink permission and six WSL checks unavailable during the mass run). The compatible Windows and Linux examples each matched Node.js in 51/51 cases, and the positive Test262 smoke manifest passed 73/73. Two Linux generator tests also passed in a separate run. The GitHub CI result remains to be checked on the pull request.
