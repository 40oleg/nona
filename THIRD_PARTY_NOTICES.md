# Third-party notices

Native compiler archives include this file and `LICENSE`. When distributing a
program generated by Nona, include both files alongside the executable. The
nondecimal formatter and cube-root support below are part of the shared runtime.
RegExp and Intl support also imports generated Unicode data; ARM64 output uses
the software logarithm and exponential helpers.

## ARM64 logarithm and exponential range reduction

The reduction constants in `src/runtime/numeric/software-math.ts` follow Sun fdlibm,
as published in OpenLibm's [e_log.c](https://github.com/JuliaMath/openlibm/blob/master/src/e_log.c)
and [e_exp.c](https://github.com/JuliaMath/openlibm/blob/master/src/e_exp.c).
Nona emits its own native instructions and convergent polynomial approximations.

## Cube-root support

`s_cbrt.c`, also used by V8 in `base/ieee754.cc`.

## Unicode data

The generated tables in `src/runtime/data/regexp-unicode-data.ts` and
`src/runtime/data/regexp-emoji-data.ts` derive from the official Unicode 17.0.0
[UCD](https://www.unicode.org/Public/17.0.0/ucd/) and
[Emoji data](https://www.unicode.org/Public/17.0.0/emoji/), respectively, through
`scripts/generate-regexp-unicode.py` and `scripts/generate-regexp-emoji.py`.
`src/runtime/regexp-vm-source.ts` imports both tables, and
`src/runtime/intl-source.ts` imports the UCD table; generated programs using
this support include Unicode-derived data.
